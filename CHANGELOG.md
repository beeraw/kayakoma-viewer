# Changelog

What changes in each version of Kayakoma Viewer. The section of a version is also what the update window shows, so it is written for the people who use the app.

## 1.1.0

- **Find** in the document: the magnifier in the toolbar, or Edit > Find (Command-F, then Command-G for the next match).
- **Four new themes**: Slate, Lagoon, Coral and Typewriter.
- The line width setting has a last step, **Window**: the text fills the whole window.
- **Updates**: the app now checks for new versions and installs them when you agree. See Settings > Updates.

## 1.0.0

- First release.
